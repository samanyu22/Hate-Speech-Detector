# Explainable AI (XAI) Framework
## Hate Speech Detection through Explainable AI and Reward Optimized LLMs

---

### 1. Grounded Attribution Principles
In high-stakes content moderation, post-hoc natural language summaries generated by ungrounded LLMs frequently hallucinate justification markers that do not exist in the input. Our XAI engine guarantees mathematical grounding through local perturbation and gradient-derived attributions.

---

### 2. Leave-One-Out Token Perturbation
Given an input text $x = (w_1, w_2, \dots, w_N)$, each word $w_j$ is ablated to yield $x_{\backslash j}$. The attribution score is calculated as:
$$\Delta_j = f_\theta(x) - f_\theta(x_{\backslash j})$$
- **Positive Evidence ($\Delta_j > 0$):** Tokens that elevate the hateful probability (slurs, dehumanization, threats).
- **Negative Evidence ($\Delta_j < 0$):** Tokens that reduce the hateful probability (counterspeech, civil discussion, quotation markers).

---

### 3. Faithfulness Validation (AOPC)
To empirically verify that attributed tokens truly govern model decisions, we execute an automated ablation test:
1. Identify the top 20% highest attributed tokens.
2. Ablate these tokens from the input to produce $x_{\text{ablated}}$.
3. Measure prediction drop:
   $$\text{Faithfulness Score} = \min\left(1.0, \frac{|f(x) - f(x_{\text{ablated}})|}{\max(0.01, f(x))}\right)$$
An attribution engine is certified faithful if ablation causes a statistically significant drop in confidence.

---

### 4. Multimodal Visual Grounding
For multimodal memes, token attributions are spatially mapped back to the meme image using EasyOCR bounding box coordinates $[y_{\min}, x_{\min}, y_{\max}, x_{\max}]$. Reviewers can visually inspect which typographic regions on the meme triggered the moderation flag.
