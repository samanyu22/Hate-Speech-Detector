1. Dataset Description & Statistics

Existing content moderation models degrade on Indic discourse due to code-mixed Latin transliteration (Hinglish), regional idioms, and multimodal memes. We curated a multi-source benchmark totaling 1,310 annotated instances:

  • HASOC Hi-En (840): English, native Hindi (Devanagari), and code-mixed Hinglish capturing informal abusive slang and civil debate.
  • HateXplain Benchmark (200): Ground-truth token-level rationale annotations for XAI faithfulness auditing.
  • Subtle & Structural Benchmark (240): Veiled stereotypes, exclusionary predicates, and counter-speech negations.
  • Multimodal Hateful Memes (30): Image memes with typography extracted via EasyOCR, capturing text-image contradictions.

Strict Binary Objective: y ∈ {0, 1} (0 = Non-Hateful, 1 = Hateful). Partitions use a leakage-safe stratified 70/15/15 split (S=42):

2. Methodology & Implementation

Mathematical Formulation: An input instance is modeled as:

x_i = {T_i, V_i, C_i} &implies; f_θ(x_i) → y_i ∈ {0, 1}
where T_i is text, V_i is visual tensor, and C_i is sanitized thread context.

Pipeline Modules:

  1. Text Preprocessing (T_i): Unicode NFKC normalization, URL/mention neutralization, Devanagari script detection (U+0900–U+097F), and phonetic Hinglish elongation reduction.
  2. Visual & OCR Extraction (V_i): Bilinear resize (224 × 224) and EasyOCR extraction yielding bounding boxes [y_min, x_min, y_max, x_max] and typography text.
  1. Model Architectures:
    • Classical Baseline: Scikit-Learn TF-IDF (word 1–2, char 2–5) + Logistic Regression (demonstrates n-gram limits).
    • Multilingual Transformer: PyTorch sequence encoder with multi-head self-attention and character subword n-gram union.
    • Intermediate Cross-Attention: Projects 128-d visual CNN maps and text tokens into shared space with sigmoid gate:
      h_fused = g ⊙ h_text + (1 - g) ⊙ CrossAttn(h_text, h_vis)
  2. Bidirectional Local Negation Scope (Way 1): Evaluates a [-2, +2] window decoupling negated slurs from zero-tolerance escalation, handling English prefixes ("not vermin") and Hindi suffixes ("harami nahi").
  3. Grounded XAI: Leave-One-Out perturbation token drop Δ_j = f(x) - f(x_{\j}), verified via Area Over Perturbation Curve (AOPC) faithfulness.
  4. Reward Optimization (DPO):
    R = αR_cls + βR_exp + γR_ctx + δR_fb - λ_err R_err
    (α=0.35, β=0.25, γ=0.15, δ=0.25, λ_err=0.50). Preference pairs (x, y_w, y_l) update policy weights via Direct Preference Optimization.

Key Findings:
• Target Grounding Limitation: Classical TF-IDF misclassifies benign insults ("you are absolutely stupid...") as Hateful (51.74%) due to n-gram presence. The Transformer correctly identifies Non-Hateful (99.5% confidence) due to lack of demographic target grounding.
• Slur Rebuttal Resolution: Way 1 Bidirectional Negation improved negated counter-speech from 65% (13/20) to 100% (20/20) without false positives.
• Multimodal Synergy: Cross-Attention achieved a +5.0% F1 gain on memes with text-image semantic contradictions.
• Test Suite: 45 / 45 automated pytest tests pass.

4. Challenges Encountered & Resolutions

  1. Code-Mixed Hinglish Tokenization Collapse:
    Problem: Standard subword tokenizers (BERT/mBERT) fracture Romanized Hindi slang into out-of-vocabulary noise.
    Resolution: Implemented script distribution analysis, phonetic transliteration dictionaries (e.g. kamine, gaddar, aukaat), and character n-gram union.
  2. The "Slur Rebuttal" False Positive Blindspot:
    Problem: Unconditional zero-tolerance slur heuristics flagged valid counter-speech defending targeted groups ("these immigrants are not vermin").
    Resolution: Engineered Bidirectional Local Negation Scope ([-2, +2] window) resolving preceding English negations (not, never) and trailing Hindi negations (nahi, mat).
  3. Double Inversion Adversarial Traps:
    Problem: Inputs negating condemnation ("I will not condemn attacks on Jews because they deserved it") attempted to exploit counter-speech protections.
    Resolution: Added local negation checks on condemnation verbs (condemn, denounce) combined with demographic subordination escalation rules.
  4. Cross-Machine Deployment Discrepancies:
    Problem: Team members pulling from GitHub encountered divergent classifications because .pt weights were ignored by default .gitignore rules.
    Resolution: Whitelisted serialized model checkpoints (multilingual_transformer.pt, multilingual-transformer-v2.331.pt) and added dynamic relative path sanitization in backend/database/db.py.

5. Future Work (Before Final Evaluation)

  • Indic Language Expansion: Extend phonetic transliteration and embedding lexicons to Dravidian languages (Tamil, Telugu, Kannada).
  • LoRA Fine-Tuning: Integrate Low-Rank Adaptation (LoRA) on open-source instruction-tuned LLMs (e.g. LLaMA-3-8B / Gemma-2-9B) for the structured reasoner.
  • Browser Extension Integration: Build a lightweight client-side Chrome extension communicating with the FastAPI backend for real-time moderation on X and YouTube.
  • Streaming Active Learning Queue: Route low-confidence inferences (< 0.70) into an automated reviewer queue for continuous DPO updates.
